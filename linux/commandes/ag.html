ag
ag — the silver searcher, a code-searching tool
"Comme grep, mais taillé pour le code : bien plus rapide, et il ignore automatiquement .git et node_modules."
Recherche ⭐⭐ Intermédiaire Pratique

C'est quoi, ag ?

ag, le « Silver Searcher », fait le même travail que grep -r mais a été conçu pour fouiller du code source. Il est nettement plus rapide sur de gros dépôts, et surtout il saute d'office ce qu'on ne veut jamais fouiller : .git, node_modules, et tout ce que liste ton .gitignore.

💡 L'analogie : grep lit toutes les pages, y compris les brouillons et les archives. ag ne lit que le manuscrit en cours.
Installation et usage
# Sur Debian / Ubuntu
$ sudo apt install silversearcher-ag
 
# Chercher un mot dans tout le projet
$ ag "TODO"
 
# Sans tenir compte de la casse
$ ag -i "erreur"

Filtrer intelligemment

Options courantes
# Seulement dans les fichiers Python
$ ag --python "import json"
 
# Afficher uniquement les noms de fichiers
$ ag -l "api_key"
 
# Forcer la recherche partout, y compris les fichiers ignorés
$ ag -u "secret"

Si ag n'est pas installé et que tu ne peux rien installer, grep -r --exclude-dir=.git --exclude-dir=node_modules fait le même travail, en plus verbeux.
