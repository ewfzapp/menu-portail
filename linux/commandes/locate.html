Commande Linux
locate
locate — find files by name, using a prebuilt index
"Trouve un fichier instantanément grâce à une base de données. Bien plus rapide que find, mais pas toujours à jour."
Recherche ⭐ Débutant ✓ Utile

C'est quoi, locate ?

locate cherche un fichier par son nom dans une base de données construite à l'avance. Le résultat est quasi instantané, même sur un disque entier — parce qu'il ne parcourt pas le disque, il lit un index.

💡 L'analogie : find fouille toute la bibliothèque rayon par rayon. locate consulte le fichier des titres. Beaucoup plus rapide, mais l'index date de la dernière mise à jour.
Utilisation de base
# Trouver tous les fichiers nommés nginx.conf
$ locate nginx.conf
 
# Sans tenir compte de la casse
$ locate -i readme
 
# Compter les résultats au lieu de les afficher
$ locate -c *.log

Le piège de l'index

Un fichier créé il y a deux minutes ne sera pas trouvé : il n'est pas encore dans la base. Celle-ci est régénérée automatiquement chaque nuit, mais tu peux forcer la mise à jour.

Rafraîchir la base
# Reconstruire l'index (nécessite les droits root)
$ sudo updatedb
 
# Ne garder que les fichiers qui existent encore
$ locate -e config

Retiens la règle : locate pour retrouver vite un fichier que tu sais présent depuis longtemps, find pour chercher avec des critères précis (taille, date, permissions) ou sur des fichiers récents.
