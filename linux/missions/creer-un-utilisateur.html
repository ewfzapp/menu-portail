Mission 11 — Débutant

Créer un compte pour un collègue

Débutant ⏱ 10 min 🔧 useradd, passwd, usermod
Le scénario
Un collègue rejoint l'équipe. Il a besoin d'un accès au serveur, mais certainement pas des pleins pouvoirs de root. Tu dois lui créer un compte propre, avec les bons droits.
01
Créer le compte utilisateur
On crée un utilisateur avec un dossier personnel automatiquement.
Créer l'utilisateur
# -m crée le dossier /home/marie, -s définit le shell par défaut
root@vps:~# useradd -m -s /bin/bash marie

# Vérifier que le compte existe
root@vps:~# id marie
uid=1001(marie) gid=1001(marie) groups=1001(marie)
💡 Astuce
Le -m est essentiel : sans lui, l'utilisateur n'a pas de dossier personnel.
02
Définir un mot de passe
Sans mot de passe, impossible de se connecter. On en fixe un temporaire.
Définir le mot de passe
root@vps:~# passwd marie
New password:
Retype new password:
passwd: password updated successfully
⚠ Attention
Demande à Marie de le changer dès sa première connexion avec passwd (sans argument, pour son propre compte).
03
Donner les droits sudo
Marie doit pouvoir installer des paquets et gérer certains services, sans être root en permanence.
Ajouter au groupe sudo
root@vps:~# usermod -aG sudo marie

# Vérifier les groupes de Marie
root@vps:~# groups marie
marie : marie sudo
💡 Astuce
Le -a (append) est crucial : sans lui, usermod -G remplace tous les groupes existants au lieu d'en ajouter un.
✅ Critères de réussite
  • Créer un utilisateur avec un dossier personnel
  • Définir un mot de passe
  • Ajouter l'utilisateur au groupe sudo
  • Vérifier que la connexion fonctionne
