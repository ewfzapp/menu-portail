Mission 03 — Intermédiaire

Sauvegarder automatiquement son serveur

Intermédiaire ⏱ 25 min 🔧 bash, tar, cron
Le scénario
Tes données sont précieuses. Un disque qui lâche, une fausse manipulation, et tout disparaît. Dans cette mission, tu vas créer un système de sauvegarde automatique qui tournera chaque nuit sans que tu aies à y penser.
01
Créer le script de sauvegarde
Un script bash qui archive un dossier avec la date du jour dans le nom.
backup.sh
#!/bin/bash
# Script de sauvegarde automatique

SOURCE="/var/www/mon-site"
DEST="/backup"
DATE=$(date +%Y-%m-%d)
LOG="/var/log/backup.log"

# Créer le dossier de destination
mkdir -p "$DEST"

# Faire la sauvegarde
echo "[$DATE] Début sauvegarde..." >> $LOG
if tar -czf "$DEST/backup-$DATE.tar.gz" "$SOURCE" >> $LOG 2>&1; then
  echo "[$DATE] ✅ Succès" >> $LOG
else
  echo "[$DATE] ❌ Échec !" >> $LOG
fi

# Garder seulement les 7 derniers backups
ls -t "$DEST"/backup-*.tar.gz | tail -n +8 | xargs rm -f
02
Rendre le script exécutable
Un script bash doit avoir la permission d'exécution pour pouvoir être lancé.
Permissions et test
# Rendre exécutable
$ chmod +x backup.sh

# Tester manuellement
$ ./backup.sh

# Vérifier que l'archive a été créée
$ ls -lh /backup/
-rw-r--r-- 1 root root 2.3M 2026-05-17 backup-2026-05-17.tar.gz

# Vérifier le contenu de l'archive
$ tar -tzf /backup/backup-2026-05-17.tar.gz | head -10
03
Automatiser avec cron
Maintenant on programme la sauvegarde pour qu'elle tourne chaque nuit à 2h sans intervention.
Configurer crontab
# Ouvrir l'éditeur crontab
$ crontab -e

# Ajouter cette ligne :
0 2 * * * /home/user/backup.sh
# ↑ = "à 2h00, chaque jour, chaque mois, chaque jour de semaine"

# Vérifier que cron est actif
$ crontab -l
💡 Tester crontab.guru
Le site crontab.guru permet de vérifier ta syntaxe cron visuellement avant de l'activer. Indispensable pour ne pas se tromper d'horaire.
✅ Critères de réussite
  • Le script backup.sh s'exécute sans erreur
  • Une archive .tar.gz est créée avec la date
  • La tâche cron est planifiée à 2h chaque nuit
  • Les vieux backups sont supprimés automatiquement
